## Layout

```
~
├── .config
│   ├── umbriel
│   │   ├── config.toml       general, input, layout, appearance
│   │   ├── binds.toml        keybinds
│   │   ├── rules.toml        window and layer rules
│   │   └── scratchpads.toml  terminal, music and discord pads
│   ├── noctalia              extra templates (luciole)
│   ├── luciole
│   ├── foot
│   ├── fish
│   └── helix
├── .local/state/noctalia
│   └── settings.toml         Noctalia settings (written by its GUI)
└── Pictures/Wallpapers
```

Theme files generated by Noctalia (`umbriel/noctalia.toml`, `luciole/colors.toml`, terminal and GTK colors) are not tracked. They are rebuilt from the current wallpaper.

## Install

The repo is a bare git repository with `$HOME` as its work tree, so files live where they belong and there are no symlinks.

```sh
git clone --bare https://github.com/Chewawi/dots.git "$HOME/.dots"
alias dots='git --git-dir=$HOME/.dots --work-tree=$HOME'
dots checkout
dots config status.showUntrackedFiles no
```

If `checkout` complains about existing files, move them out of the way and run it again.

### Packages

```sh
doas apk add foot fish helix fonts-nerd-jetbrains-mono stb
```

Umbriel, Noctalia and Luciole are built from source. See their docs.

### Building Luciole on Chimera

Chimera uses libc++, and libc++ 22 does not ship `std::move_only_function` yet, so Luciole needs a small fallback header until that lands. Chimera also installs the stb header without its `stb/` directory:

```sh
doas mkdir -p /usr/local/include/stb
doas ln -s /usr/include/stb_image_resize2.h /usr/local/include/stb/stb_image_resize2.h
```
