## Layout

Everything under `home/` is linked into `$HOME` at the same path.

```
home
├── .config
│   ├── umbriel
│   │   ├── config.toml       input, layout, appearance, autostart
│   │   ├── binds.toml
│   │   ├── rules.toml        window and layer rules
│   │   └── scratchpads.toml  terminal, music and Discord
│   ├── noctalia
│   │   └── luciole.toml      extra color template for Luciole
│   ├── fish
│   ├── foot
│   ├── helix
│   ├── gtk-3.0
│   └── starship.toml
├── .local/state/noctalia
│   └── settings.toml         Noctalia settings, written by its settings window
└── Pictures/Wallpapers
```

The color files Noctalia writes on every wallpaper change (`umbriel/noctalia.toml`, `foot/themes/`, `helix/themes/`, `luciole/colors.toml`, GTK, Qt, btop...) are not tracked. See `.gitignore`.

Noctalia also reads every `*.toml` in `~/.config/noctalia`. I keep machine-specific settings (location, avatar) in `~/.config/noctalia/local.toml`, which is ignored.

## Install

```sh
git clone https://github.com/Chewawi/dots.git ~/dots
~/dots/install.sh -n   # dry run
~/dots/install.sh
```

`install.sh` symlinks each file in `home/` to the same place in `$HOME`. If a file is already there, it is moved to `~/dots-backup/` first. Running it again only adds what's missing.

In fish, `dots` is `git -C ~/dots`.

### Packages

```sh
doas apk add foot fish-shell helix starship zoxide fonts-nerd-jetbrains-mono gnome-keyring stb
```

Umbriel, Noctalia and Luciole are built from source; see their docs. Google Sans Flex is not packaged, so get it from Google Fonts.

### Building Luciole on Chimera

Chimera uses libc++, and libc++ 22 does not ship `std::move_only_function` yet, so Luciole needs a small fallback header until that lands. Chimera also installs the stb header without its `stb/` directory:

```sh
doas mkdir -p /usr/local/include/stb
doas ln -s /usr/include/stb_image_resize2.h /usr/local/include/stb/stb_image_resize2.h
```

## Keybinds

`Mod` is Super.

| Keys | Action |
|---|---|
| `Mod` | Launcher |
| `Mod+Return` | Terminal |
| `Mod+E` | File manager |
| `Mod+BackSpace` | Close window |
| `Mod+Space` | Next keyboard layout (us / es) |
| `Mod+S` | Control center |
| `Mod+Shift+Comma` | Noctalia settings |
| `Mod+V` | Clipboard history |
| `Alt+Tab` | Window switcher |
| `Mod+O` | Overview |
| `Mod+Tab` | Last workspace |
| `Mod+T` / `Mod+M` / `Mod+D` | Terminal / music / Discord scratchpad |
| `Mod+Arrows`, `Mod+HJKL` | Move focus |
| `Mod+Ctrl+Arrows` | Move window or column |
| `Mod+1..9` | Switch workspace |
| `Mod+Shift+1..9` | Send column to workspace |
| `Mod+R` | Cycle column width |
| `Mod+F` | Maximize |
| `Mod+Shift+F` | Fullscreen |
| `Mod+Ctrl+F` | Maximize to edges |
| `Mod+Alt+F` | Toggle floating |
| `Mod+W` | Tabbed column |
| `Mod+Shift+S` | Region screenshot with annotations |
| `Print` / `Ctrl+Print` / `Alt+Print` | Screenshot region / screen / window |
| `Mod+Shift+Slash` | Cheatsheet |
| `Mod+Shift+Escape` | Quit session |

The full list is in [`binds.toml`](home/.config/umbriel/binds.toml).
